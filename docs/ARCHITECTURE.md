# Архитектура

## Принцип

Количественный движок — источник истины. AI-слой только формулирует то,
что движок посчитал, и не имеет права породить ни одного числа.

Поток данных односторонний:

```
CFTC / FRED  →  cot_raw (append-only)
                    ↓
             cot_processed  (метрики по участникам)
                    ↓
             market_states  (широкая таблица, режимы, форвардные доходности)
                    ↓
      ┌─────────────┼─────────────┬──────────────┐
      ↓             ↓             ↓              ↓
  analog engine  validation   event study    scanner
      ↓             ↓             ↓              ↓
              evidence (доказательная база)
                    ↓
              site/index.html
```

Сырой слой не переписывается никогда. Производные пересобираются целиком.

## Модули

| Путь | Отвечает за |
|---|---|
| `config/markets.py` | Реестр инструментов: код, сектор, отчёт, поиск контракта, источники цены, размер пункта |
| `config/settings.py` | Окна, пороги, наборы признаков, правила режимов |
| `src/data/availability_guard.py` | **Единая** защита от заглядывания в будущее |
| `src/data/availability.py` | report_date против availability_date |
| `src/data/cftc_client.py` | TFF и Disaggregated, поиск контракта по подстроке |
| `src/data/price_client.py` | FRED и Stooq, перебор кандидатов |
| `src/data/db.py` | SQLite, миграции выводятся из схемы |
| `src/cot/` | Метрики, перцентили, z-score, режимы, расхождения |
| `src/price/` | Конвенция котировок, форвардные доходности |
| `src/analogs/similarity.py` | Взвешенное расстояние по стандартизованным признакам |
| `src/analogs/sampling.py` | Три режима выборки, блочный бутстрап, эффективный размер |
| `src/analogs/evidence.py` | Доказательная база под каждым утверждением |
| `src/analogs/multiple_testing.py` | FDR, режимы разведки и подтверждения |
| `src/events/validation.py` | Проверка на истории, обратный взгляд от движений |
| `src/events/event_study.py` | Окна до и после события, эпизоды |
| `src/ai/` | Формулировки поверх посчитанного |

## Единственный источник правды

Реестр рынков и настройки живут только в Python. Сайт получает их
запечёнными в `index.html` при сборке. Дублирования конфигурации между
бэкендом и фронтендом нет.

## Почему статический сайт

Нет сервера, нет зависимостей у пользователя, работает офлайн, публикуется
на GitHub Pages бесплатно. Все расчёты делает Python при сборке; браузер
только рисует.
