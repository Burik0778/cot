КАК СДЕЛАТЬ ИЗ ЭТОГО САЙТ В ИНТЕРНЕТЕ
=====================================

Результат: постоянная ссылка вида
    https://ВАШ-ЛОГИН.github.io/cot/

Заходите с компьютера, с телефона, откуда угодно. Сайт сам обновляется
каждую субботу — сервер GitHub скачивает свежий отчёт CFTC и пересобирает
страницу. Ваш компьютер при этом может быть выключен.

Всё бесплатно. Python на вашем компьютере не нужен вообще.

Настройка занимает минут 15. Делается один раз.


──────────────────────────────────────────────────────────
ШАГ 1. Аккаунт на GitHub
──────────────────────────────────────────────────────────

Откройте  https://github.com/signup

Заведите бесплатный аккаунт. Логин выбирайте латиницей — он попадёт
в адрес вашего сайта.

Подтвердите почту, иначе следующий шаг не сработает.


──────────────────────────────────────────────────────────
ШАГ 2. Создать репозиторий
──────────────────────────────────────────────────────────

Откройте  https://github.com/new

  Repository name    cot
  Ниже выберите      Public
                     (обязательно: на бесплатном тарифе Pages
                      работает только для публичных репозиториев)

  Галочки "Add a README", ".gitignore", "license" НЕ ставьте.

Нажмите зелёную кнопку  Create repository


──────────────────────────────────────────────────────────
ШАГ 3. Загрузить файлы
──────────────────────────────────────────────────────────

На открывшейся странице найдите ссылку
    uploading an existing file
(в тексте "…or push an existing repository…" рядом есть эта ссылка;
 либо откройте  https://github.com/ВАШ-ЛОГИН/cot/upload/main )

Распакуйте архив у себя на компьютере. Откройте распакованную папку.

Выделите ВСЁ содержимое папки (Ctrl+A) и перетащите мышкой в окно
браузера, в область загрузки.

ВАЖНО: перетаскивать надо содержимое папки, а не саму папку.
То есть в браузер должны уехать: папки config, scripts, src, tests,
docs, site_template, файл requirements.txt и остальные.

Скрытая папка .github тоже нужна — именно в ней лежит инструкция
для автообновления. Если Windows её не показывает:
    Проводник → вкладка "Вид" → галочка "Скрытые элементы"

Дождитесь, пока все файлы прогрузятся (внизу появится их список).

Внизу страницы нажмите зелёную кнопку  Commit changes


──────────────────────────────────────────────────────────
ШАГ 4. Включить публикацию
──────────────────────────────────────────────────────────

В вашем репозитории откройте вкладку  Settings  (сверху справа)

Слева в меню выберите  Pages

В разделе "Build and deployment", в поле  Source
выберите из выпадающего списка:   GitHub Actions

Больше на этой странице ничего трогать не нужно.


──────────────────────────────────────────────────────────
ШАГ 5. Запустить первую сборку
──────────────────────────────────────────────────────────

Откройте вкладку  Actions  (сверху)

Слева выберите  "Собрать и опубликовать сайт"

Справа нажмите кнопку  Run workflow → ещё раз  Run workflow

Начнётся сборка. Займёт 2-4 минуты: сервер скачает данные CFTC,
прогонит тесты и опубликует сайт.

Обновите страницу — увидите жёлтый кружок (идёт) или зелёную
галочку (готово). Красный крестик — что-то не так, нажмите на него
и покажите мне текст ошибки.


──────────────────────────────────────────────────────────
ШАГ 6. Открыть свой сайт
──────────────────────────────────────────────────────────

Settings → Pages — вверху будет написан адрес вашего сайта.

Обычно это:
    https://ВАШ-ЛОГИН.github.io/cot/

Первый раз адрес может появиться через пару минут после сборки.

Добавьте в закладки. На телефоне — "Добавить на главный экран",
будет как приложение.


──────────────────────────────────────────────────────────
ЧТО ДАЛЬШЕ
──────────────────────────────────────────────────────────

Ничего. Сайт обновляется сам каждую субботу утром.

CFTC публикует отчёт в пятницу в 15:30 по Нью-Йорку — это примерно
23:30 по Ташкенту, с данными на прошедший вторник. Сборка запускается
в субботу, так что к вашему утру данные уже свежие.

Хотите обновить прямо сейчас, не дожидаясь субботы:
    Actions → "Собрать и опубликовать сайт" → Run workflow


──────────────────────────────────────────────────────────
ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
──────────────────────────────────────────────────────────

Сборка красная (крестик)
    Actions → нажмите на неудачный запуск → раскройте красный шаг →
    скопируйте текст ошибки и покажите мне.

"There isn't a GitHub Pages site here"
    Не выполнен ШАГ 4, либо сборка ещё не закончилась.

Сайт открылся, но пустой
    Значит сборка прошла, а данные не скачались. Посмотрите в Actions
    шаг "Скачать данные CFTC и FRED".

Репозиторий сделали Private
    На бесплатном тарифе Pages не работает с приватными.
    Settings → внизу "Change repository visibility" → Public.


──────────────────────────────────────────────────────────
ЕСЛИ ХОТИТЕ РАБОТАТЬ ЛОКАЛЬНО
──────────────────────────────────────────────────────────

Публикация в интернет не обязательна. Файл START.bat собирает тот же
самый сайт у вас на компьютере, в site\index.html — см. INSTRUKCIYA.txt.
Но тогда обновлять данные придётся вручную, запуская START.bat.
